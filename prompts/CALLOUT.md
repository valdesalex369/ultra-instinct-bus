# ORBITAL CALLOUT

One block. Giant emits. Alex clicks Phantom if he agrees.

```
CALLOUT
from: orbital/phantom
to: alex
venue: phantom-sol
asset: SOL | BTC | ETH | FLAT
stance: watch | long | short | flat
size_hint: 0
conviction: -1.00 to +1.00
why: one sourced sentence
kill: one halt
you_click: true
nova: leave this block on the bus as type=signal
```

Rules
- size_hint 0 until Alex countersigns a paper size in a `from: alex` message
- meme / unnamed token = FLAT
- no seed, no private key, no “send it for me”
